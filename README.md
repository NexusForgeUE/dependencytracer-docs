# Dependency Tracer documentation

Public user guide for Dependency Tracer 1.1.0, an Unreal Engine editor plugin by NexusForgeUE.

Site: https://nexusforgeue.github.io/dependencytracer-docs/

Languages: English (`index.html`), Simplified Chinese (`zh-Hans/`), Russian (`ru/`), Spanish (`es/`), Brazilian Portuguese (`pt-BR/`), German (`de/`), Japanese (`ja/`), French (`fr/`) and Korean (`ko/`). The language selector preserves the current chapter.

All assets are local; chapter search runs in the browser. GitHub Pages serves the `main` branch from the repository root. The `.nojekyll` file enables direct static-file hosting.

The site contains documentation and real plugin screenshots only. Commercial plugin source, release binaries, test projects and internal validation logs are not published here.

The documentation shell is adapted from the same publisher's LocDoctor guide. Product instructions are checked against Dependency Tracer's actual UI, settings, audit rules and exports. Screenshot captions explain that the displayed size figures come from a demonstration project and are estimates based on saved asset packages.
